# Tego dnia

Wpisujesz dzień i miesiąc — dostajesz kilka wydarzeń, które przydarzyły się wtedy na świecie i w Polsce, oraz jedno, wyróżnione, z ilustracją.

Statyczna strona (`index.html`), bez budowania — dane pobierane na bieżąco z publicznego API Wikipedii (`pl.wikipedia.org/api/rest_v1/feed/onthisday`). Podział na „świat” i „Polskę” jest prostą heurystyką słów kluczowych, nie idealną klasyfikacją.

## Uruchomienie lokalnie

Otwórz `index.html` w przeglądarce — nic więcej nie jest potrzebne.

## GitHub Pages

Ustawienia repozytorium → Pages → Source: branch `gh-pages`, folder `/ (root)`.
